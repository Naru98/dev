# Narayan Rahul — Freelance Website

A responsive single-page freelance portfolio website built with plain HTML, CSS and JavaScript.

## Includes
- Freelance-focused hero section
- Services for websites, web apps, business systems, e-commerce and local shops
- Selected projects based on the supplied resume
- Development process
- About / skills
- Email and WhatsApp CTAs
- Responsive mobile navigation
- No build tools required

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Customize
Edit `index.html` for text, projects and contact details.
Edit `style.css` for colors, typography and layout.
